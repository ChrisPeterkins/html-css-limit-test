02 Boolean switchboard

Route the
signal.

Toggle inputs A and B. Three logic gates recalculate from checkbox state using relational selectors. This is actual Boolean behavior expressed in CSS.

Reveal the mechanism 
.board:has(#a:checked):has(#b:checked) .and {
  --output: 1;
}

.board:has(#a:checked):not(:has(#b:checked)) .xor {
  --output: 1;
}
Boolean inputs and outputs
AND01A · B
OR01A + B
XOR01A ⊕ B

03 Typed custom property

Animate the
value itself.

@property gives a CSS variable a type, initial value, and interpolation behavior. The browser can animate an angle directly through a generated gradient.

Reveal the mechanism 
@property --reactor-angle {
  syntax: "<angle>";
  initial-value: 0deg;
  inherits: false;
}

@keyframes reactor { to { --reactor-angle: 360deg; } }
