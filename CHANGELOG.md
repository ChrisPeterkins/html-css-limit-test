# Changelog

All notable changes to this project are documented here.

## 2.0.0 — 2026-08-29

- Added the Cascade Engine as a cohesive, playable CSS-only centerpiece.
- Added scroll-driven machine assembly using a named view timeline and a stable fallback.
- Added a three-relay exact-state routing puzzle with a physically opening vault.
- Added a six-faced CSS 3D inspection model with radio-controlled viewpoints and native popover annotations.
- Added a 144-combination generative poster forge with palettes, geometries, voices, formats, detail, and motion states.
- Added a print manufacturing mode that outputs only the active poster composition.
- Added a document X-ray mode that exposes semantic HTML structure in the rendered interface.
- Added a named cross-document core morph from the Control Room to the Cascade Engine.
- Expanded repository quality checks to validate IDs, local links, stylesheet balance, and prohibited runtime assets.

## 1.1.0 — 2026-08-29

- Added the CSS-only Control Room with live feature-query indicators.
- Added an interactive AND, OR, and XOR Boolean switchboard using `:has()`.
- Added a typed custom-property reactor with speed, direction, and pause controls.
- Added native status meters and a keyboard-focusable scroll-snap protocol deck.
- Added eight reader-controlled typography configurations to the field guide.
- Added a fully navigable CSS-only mobile menu across every page.
- Expanded responsive and keyboard-focus coverage for the new controls.

## 1.0.0 — 2026-08-29

- Launched the three-page HTML and CSS exhibition.
- Added a 36-state CSS composition laboratory.
- Added six inspectable native-browser capability exhibits.
- Added cross-document view transitions and scroll-linked motion.
- Added dark theme, reduced-motion, increased-contrast, and print modes.
- Added a performance receipt and zero-dependency verification workflow.
- Added project governance, contribution, security, and licensing documents.
